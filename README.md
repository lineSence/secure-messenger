# secure-messenger

Uncensored — личный мессенджер со сквозным шифрованием для общения в РФ во время блокировок. Для своего круга: 2–5 человек на Android. Код пишут ИИ-агенты, решения принимает владелец. Репозиторий публичный (ADR-51).

## Что уже есть
- `v0.0.1-alpha`: переписка 1:1 по Bluetooth рядом (~10 м), только текст, шифрование Signal (libsignal). Что вошло, ограничения и известные недочёты — `releases/v0.0.1-alpha.md`.
- Дальше: интернет через свой узел и ссылка-приглашение (0.0.2-alpha), обходные пути (0.0.3-alpha), группы (0.2.0), второе устройство (0.3.0), LoRa (0.5.0).

## Устройство репозитория
- `crates/` — ядро на Rust: `sm-core` (форматы сообщений и кадров, очередь, хранилище ключей, интерфейс транспортов), `sm-signal` (libsignal), `sm-ffi` (привязки UniFFI для Android), `sm-relay` (узел-реле: очереди зашифрованных блобов, без логов; в приложение пока не подключён).
- `android/` — приложение на Kotlin/Compose.
- `fuzz/` — цели фаззинга; `scripts/`, `tools/` — сборка ядра и вспомогательное.
- `wiki/` — архитектура, решения (ADR), факты с источниками, правила и порядок работы; `design/` — макеты интерфейса и значки.
- `releases/` — заметки выпусков; `.github/` — конвейер CI, подпись релиза, вердикты ИИ-ревью.

## С чего начать
- `wiki/architecture/overview.md` — как устроено и от чего защищаемся.
- `wiki/architecture/decisions.md` — принятые и предложенные решения.
- `wiki/workflows/releases.md` — план выпуска по пунктам; `wiki/workflows/ci.md` — проверки и как прогнать их локально.
- `wiki/references/` — факты с источниками и датами: транспорт, криптография, серверы, право.

## Установка
APK — со страницы релиза на GitHub; SHA-256 файла и сертификата подписи сверить с `releases/vX.Y.Z.md` (ADR-76).

## Знания агента (SEK)
Репозиторий ведётся по SEK (Self-Evolving Knowledge) из `sek-library`: главная инструкция агента — `AGENTS.md`, знания — `wiki/`, черновики — `memory/inbox.md`. Проверка структуры: `node scripts/sek-lint.mjs` (Node.js 18+).
Инструкция агента — в `AGENTS.md`. Прочитай его и следуй ему.
