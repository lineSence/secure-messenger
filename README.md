# secure-messenger

Личный мессенджер со сквозным шифрованием для общения в РФ во время блокировок. Стадия — проектирование: здесь только документация, кода пока нет. Репозиторий приватный, проект не публикуется.

## С чего начать
- `wiki/architecture/overview.md` — как устроено и от чего защищаемся.
- `wiki/architecture/decisions.md` — решения, которые нужно принять.
- `wiki/workflows/mvp.md` — план по шагам.
- `wiki/references/` — факты с источниками и датами: транспорт, криптография, серверы, право.

## Знания агента (SEK)
Репозиторий ведётся по SEK (Self-Evolving Knowledge) из `sek-library`: главная инструкция агента — `AGENTS.md`, знания — `wiki/`, черновики — `memory/inbox.md`. Проверка структуры: `node scripts/sek-lint.mjs` (Node.js 18+).
