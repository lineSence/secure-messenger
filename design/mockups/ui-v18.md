Дата: 2026-10-14. **Статус: принят владельцем — «Принято, реализуй» (2026-10-14). Реализация — PR #92; согласование макета не заменяет приёмку Android.**
Макет: `design/mockups/ui-v18.html`. Предыдущий v17 отклонён целиком.
Аудит: `wiki/audits/2026-10-14-ux-ui/report.md`, проверенный SHA `0ccfbaa80eba483ea6c2cf6b83a6b80026235bae`.

## Основа и границы

v18 — копия исходного `ui-v14.html` с отдельным слоем точечных изменений, не набор новых самостоятельных экранов. Сохранены оформление шапки/аватара, фон переписки, пузырьки, композер, список, SVG-значки и кнопки. Нижняя навигация есть только на корневых «Чаты / Связь / Настройки». «Новый контакт» сохраняет «Мой QR / Сканировать / Рядом / Ссылка». Создание ссылки и удаление остаются нижними листами.

Новые состояния появляются там, где выполняется операция: ошибка истории в чате; ошибка отправки рядом с прежним композером; разрыв Bluetooth во вкладке «Рядом»; отсутствие гостевого пропуска в листе созданной ссылки; ошибка записи узла в прежней предварительной проверке. Debug-логи повторяют структуру текущего debug-экрана, а не отдельный демонстрационный экран с закреплённой кнопкой.

Сценарии и моделирование сбоев вынесены в панель вне телефона. Переключатель сравнения показывает исходный v14 без слоя поправок. Изменение контрастных цветов — отдельная опция, по умолчанию выключена. Увеличение текста меняет достижимость содержимого и перенос кнопок, не общий дизайн. В малом окне при 200% пары действий листа располагаются вертикально, тело прокручивается независимо.

Онбординг v16 не откатывается и не пересматривается. Будущие функции с отметкой «Скоро» не включены в аудит как дефекты. Макет использует только синтетические значения; не выполняет реальное шифрование, сетевой обмен, импорт пропусков или работу с Android permissions.

## Просмотр

18 контекстных сценариев в панели: исходный список; ошибка истории; ранняя история/новые сообщения; отказ сохранения сообщения; нейтральный статус ключа; ошибка в превью; разрыв рядом; сохранённый контакт с незавершённым обменом; создание ссылки; отсутствие гостевого пропуска; лимит приглашений; отказ локального сохранения; уведомления; Idle; запись узла; debug-журнал; лист удаления; отказ восстановления маршрута.

Уведомления и работа в фоне остаются отдельными пунктами существующего экрана. Контекстный opt-in первого чата требует сохранения принятого потока v16 и отдельной Android-проверки; v18 не заменяет его новой страницей разрешений. Приглашение держится в памяти при rotation, не записывается в Bundle; process death требует повторной вставки. HTML не является тестом этой Android-политики.

## Проверки этой итерации

- Chromium: 18 маршрутов без JS-ошибок и горизонтального переполнения страницы.
- Playwright: при отказе отправки `QA draft` остаётся; после успешного повтора композер пуст; переключатель защиты кода меняется одним действием; новое событие активирует выгрузку debug-журнала.
- Визуально просмотрены основной список, все 18 сценариев, ошибки отправки/удаления, открытие сохранённого контакта, четыре отказа записи/пропуска; ключевые листы и история в тёмной теме; создание/передача/удаление при 200% в малом окне; ширина страницы 390 px.
- Тело корневого списка в режиме исходный/предложенный совпадает пиксельно (служебная статусная строка исключена из сравнения).
- Запущен штатный `node scripts/sek-lint.mjs`.
- Native Android, TalkBack, NotificationManager, SQLite/Keystore fault/kill, реальные сети и телефоны **не проверялись заново в этой итерации**. Старые результаты PR не выдаются за проверку нового UI. `tools/ui-shots/run.sh` и `ci-ok` остаются обязательными при реализации/приёмке Android.
