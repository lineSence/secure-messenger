# Uncensored 0.0.1-alpha — «Bluetooth рядом»

Первый релиз (ADR-57, ADR-59): Android-приложение, в котором два телефона рядом без интернета добавляют друг друга и переписываются по Bluetooth LE со сквозным шифрованием Signal. Получают владелец и ещё один человек.

- Кандидат: ветка `release/v0.0.1-alpha`, PR в `main` (ADR-58 п.4). Тег `v0.0.1-alpha` ставится после слияния; по тегу `.github/workflows/release.yml` собирает и подписывает APK ключом владельца (ADR-76).
- Версия: `appVersion = "0.0.1-alpha"` в `android/app/build.gradle.kts`, файл `uncensored-0.0.1-alpha.apk` (ADR-78).
- Android 12 и новее (minSdk 31, ADR-45), только arm64.

## Заглушки «Скоро»
Видны на своих местах, по нажатию показывают лист «Появится в версии …» и ничего не делают (макет `design/mockups/ui-v10.html`, `android/app/src/main/java/dev/sm/messenger/ui/Soon.kt`):
- 0.0.2-alpha — интернет через свой узел, ссылка-приглашение, «Сведения о сообщении»;
- 0.0.3-alpha — обходные пути, проверка связи и история;
- 0.1.0-beta — обновления из приложения;
- 0.2.0 — группы, папки «Личные» и «Группы»;
- 0.3.0 — мои устройства, подключение второго устройства;
- 0.5.0 — LoRa (Reticulum);
- позже — поиск, панель эмодзи, фото и файлы, реакции и ответы, файл или QR, оформление, блокировка приложения, конфиденциальность, уведомления чата, исчезающие сообщения, удаление контакта, изменение имени, сверка по QR.

## Ограничения
- Связь только по Bluetooth рядом, ~10 м; только текст; только чаты 1:1.
- Пока Bluetooth рядом включён, сканер поблизости видит устройство с меняющейся меткой; чьё оно, понимает только контакт (ADR-61).
- `applicationId` пока `dev.sm.messenger`; его смена до 0.1.0-beta (ADR-77) сделает новую версию отдельным приложением — переписка не перенесётся.
- Копии ключей и переписки нигде нет: потерянный или сброшенный телефон — потерянная переписка.
- **На телефонах не проверено.** До выдачи второму человеку — проверка владельцем на двух телефонах по пункту «Готово, когда» в `wiki/workflows/releases.md`.

## ИИ-ревью (ADR-58)
- Объём — весь код репозитория (первый релиз), без документации (`wiki/`, `design/`, `memory/`, `releases/`, `*.md`), `Cargo.lock`, `fuzz/Cargo.lock`, `verification-metadata.xml`, `supply-chain/` и `.github/ai-review/`. Около 16 тыс. строк в ~100 файлах.
- Ревьюируемая голова (`reviewed_head`) — в промпте ревью; после вердиктов в ветке меняется только `.github/ai-review/releases/v0.0.1-alpha.json`.
- Вердикты: `.github/ai-review/releases/v0.0.1-alpha.json` — 8 прогонов, номер прогона — порядок записи.
- critical/high: _ждём вердиктов_ — исправление отдельным PR, затем повторное ревью по diff (2 прогона).
- medium/low (исправить до следующего релиза): _ждём вердиктов_.

## Установка
1. Скачать APK со страницы релиза на GitHub.
2. Сверить SHA-256 файла с этой страницей.
3. Разрешить установку из этого источника и установить. Первый запуск: имя → ключи → разрешения «Уведомления» и «Работа в фоне».
