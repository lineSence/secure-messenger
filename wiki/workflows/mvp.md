# План MVP

Порядок шагов. Каждый шаг закрывается проверкой из колонки «Готово, когда».

| # | Шаг | Готово, когда |
|---|---|---|
| 1 | Сервер-реле (Rust или Go): очереди зашифрованных блобов в RAM, TTL, без логов | два клиента обмениваются блобами через сервер; рестарт сервера стирает всё |
| 2 | Android-клиент + libsignal, добавление контакта по QR | сообщение 1:1 доходит и расшифровывается; смена ключа блокирует отправку |
| 3 | Встроить sing-box/Xray: VLESS + XHTTP + Reality | работает через мобильных операторов минимум в двух регионах |
| 4 | Лестница транспортов и автопереключение | при блокировке основного сообщение уходит запасным без действий пользователя |
| 5 | Запасные пути при белых списках: TURN, DNS-туннель, почта | доставка при включённых белых списках |
| 6 | Офлайн: Bluetooth / Wi-Fi рядом | доставка между двумя телефонами без сети |
| 7 | Группы на OpenMLS | группа из 3+ человек, добавление и удаление участника |
| 8 | Независимая проверка криптографии и работы с ключами | отчёт проверки, найденное исправлено |

Перед шагами 3–5 — перепроверить статус транспортов по [DOCS-RECHECK-BEFORE-USE].
