# SEK — протокол самообучения

## REGISTER (draft)
Пиши в `memory/inbox.md` сразу, без просьбы владельца, если:
1. система повела себя не так, как ожидалось (баг, edge case);
2. найден workaround;
3. обнаружено недокументированное или неочевидное поведение API/библиотеки/инструмента;
4. владелец явно поправил тебя.
Перед записью — grep по inbox и wiki (по тегу и ключевым словам): тема есть в inbox → увеличь «Повторов», новую запись не создавай; тема уже есть в wiki → это не новое знание, обнови правило или факт при необходимости.
Inbox полон (20) → сначала PROMOTE кандидатов, затем удали самую старую запись с «Повторов: 1».

## PROMOTE draft → validated (автономно)
Кандидат: «Повторов» ≥ 2, или 3+ записи на одну тему, или владелец подтвердил.
Поправка владельца в форме общего правила («всегда…», «никогда…», «у нас принято…») = подтверждение, можно повышать сразу.
1) Lint.
2) Выбери место: «делай / не делай» → правило с новым ID в `wiki/rules/*.md` (с полем «Переносимость»); факт о том, как что-то устроено или ведёт себя → `wiki/references/*.md`.
3) Удали запись из inbox.
4) Новый файл → добавь в `_routing.md` и `_index.md`.
5) В ответе: `📚 Promoted: [TAG] → путь к файлу`.

## PROMOTE validated → core (только с разрешения)
«Применений» ≥ 5 за последний месяц или ошибка по правилу дорогая → предложи:
«Правило [TAG] применялось N раз за месяц. Промоутить в Critical Rules?» Без «да» L0 не трогать.
После «да»: перенеси правило в Critical Rules одной строкой с тем же ID и удали его блок из wiki/rules (подробное «почему», если нужно, оставь в wiki без ID, со ссылкой «см. [TAG] в L0»). Дублировать ID в L0 и wiki нельзя.

## Защита
- Правило младше 7 дней («Добавлено») применяется впервые → `🆕 Using recently promoted: [TAG]. Если поведение не совпадает — /revoke [TAG]`.
- `/revoke [TAG]` → удалить правило из wiki, в `memory/revoked.md` записать дату, тег, причину, кто отозвал и полный текст правила.
- `/revoke` для core-правила: команда владельца и есть разрешение править L0 — удали строку из Critical Rules и запиши в `memory/revoked.md` так же. Сам предложить отзыв core можешь, удалить без команды владельца — нет.
- Противоречие между правилами или с core → не выбирай сам, спроси владельца.

## Lint Protocol
- ID уникален во wiki и L0, формат [AREA-NAME]; у правила есть строки «Правило:» и «Добавлено: ГГГГ-ММ-ДД».
- Отозванный ID не встречается в wiki и L0.
- Правило проверяемо, без общих слов («будь внимателен» — не правило).
- Не противоречит другим правилам и core.
- inbox ≤ 20; записи старше 30 дней без повторов удалить (lint предупреждает, удаляешь ты).
- Все файлы из `_routing.md` и из таблицы триггеров L0 существуют; все файлы wiki есть в `_index.md`.
- L0 ≤ 6000 символов.
