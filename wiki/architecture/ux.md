# UX / UI

Правило: [UI-MOCKUP-FIRST] (L0) — вариант UI принимается только после просмотра интерактивного макета. Статусы UX-решений: предложено · принято · отклонено.

## Макеты
| Файл | Что внутри | Статус |
|---|---|---|
| `design/mockups/ui-v1.html` | Android: список чатов, чат, добавление контакта (QR / ссылка), сверка кода, смена ключа, «Связь» (диагностика + отчёт группе), настройки, устройства и перенос истории, LoRa, обновления. Переключатели: навигация А/Б, состояние связи, тёмная тема | на просмотре у владельца (2026-10-09) |

Открыть: скачать файл и открыть в браузере (работает без интернета).

## Предложенные UX-решения (v1)
| # | Решение | Статус | Основание |
|---|---|---|---|
| UX-1 | Навигация: А — нижние вкладки «Чаты · Связь · Настройки»; Б — один список чатов, остальное в меню | предложено, выбрать по макету | — |
| UX-2 | Плашка состояния связи над списком чатов (зелёная / жёлтая / красная), по нажатию — экран «Связь» | предложено | R-8, ADR-13 |
| UX-3 | Статус сообщения: «в очереди» → «на сервере · канал»; отчётов о прочтении нет | предложено | overview: метаданные |
| UX-4 | Контакт по ссылке — метка «не сверен» и баннер в чате до сверки | предложено | ADR-23 |
| UX-5 | Смена ключа контакта — красная карточка, отправка заблокирована до сверки | предложено | overview: подмена ключей |
| UX-6 | Экран «Связь»: что работает по типам данных, список каналов, кнопка «Отправить отчёт», статусы участников | предложено | ADR-13, ADR-19 |
| UX-7 | Подключение устройства — QR с основного телефона и прогресс переноса истории | предложено | ADR-17 |
| UX-8 | Обновление — показывает «подпись верна» до кнопки «Установить»; при несовпадении установки нет | предложено | ADR-21 |
| UX-9 | LoRa — отдельный экран: модуль, заряд, узлы рядом, режим «только без интернета» | предложено | ADR-18 |
