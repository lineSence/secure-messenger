# UX / UI

Правило: [UI-MOCKUP-FIRST] (L0) — вариант UI принимается только после просмотра интерактивного макета. Правило [UI-NO-EMOJI] — `wiki/rules/ui.md`. Факты-гайдлайны — `wiki/references/ux-guidelines.md`. Статусы: предложено · принято · отклонено.

## UX-решения
| # | Решение | Статус | Основание |
|---|---|---|---|
| UX-1 | Навигация — только нижняя панель «Чаты · Связь · Настройки»; боковое меню отклонено | принято (2026-10-09) | `ux-guidelines.md`: M3, NN/g |
| UX-2 | Полоса состояния связи видна всегда, по нажатию — экран «Связь» | принято (2026-10-09) | R-8; эвристика NN/g №1 |
| UX-3 | Статус сообщения показывает канал: «в очереди» → «12:45 · VLESS ✓✓»; отчётов о прочтении нет | принято (2026-10-09) | overview: метаданные |
| UX-4 | Контакт по ссылке — метка «не сверен» и баннер в чате до сверки | принято (2026-10-09, в составе макета v4) | ADR-23 |
| UX-5 | Смена ключа контакта — красная карточка, отправка заблокирована до сверки | принято (2026-10-09, в составе макета v4) | overview: подмена ключей |
| UX-6 | Отчёт диагностики группе — и автоматически при смене состояния связи (переключатель), и вручную кнопкой | принято (2026-10-09) | ADR-19 |
| UX-7 | Подключение устройства — QR с основного телефона и прогресс переноса истории | принято (2026-10-09, в составе макета v4) | ADR-17 |
| UX-8 | Обновление — «подпись верна» до кнопки «Установить»; при несовпадении установки нет | принято (2026-10-09, в составе макета v4) | ADR-21 |
| UX-9 | LoRa — отдельный экран: модуль, заряд, узлы рядом, режим «только без интернета» | принято (2026-10-09, в составе макета v4) | ADR-18 |
| UX-10 | Тема — как в системе, без своего переключателя | принято (2026-10-09) | `ux-guidelines.md`: dark theme |
| UX-11 | Все значки — свои SVG (сетка 24 dp, кнопки 48 dp); эмодзи только в сообщениях | принято (2026-10-09) | [UI-NO-EMOJI]; M3 touch target |
| UX-12 | Внешний вид ближе к Telegram для Android 2026, но не копия; кандидаты — варианты 1, 3, 7, 8 | принято (2026-10-09): основа — Классика (1) + папки (7) + статус-полоса (8); Компакт (3) — настройка, см. UX-16 | выбор владельца 2026-10-09 |
| UX-13 | Анимации: переходы экранов 350–400 мс с emphasized decelerate, мелкие — 200–300 мс со standard; при системной «Убрать анимацию» — без анимаций | принято (2026-10-09) | `ux-guidelines.md`: M3 motion, WCAG 2.3.3 |
| UX-14 | Реакции: касание сообщения — меню с 7 реакциями; двойное касание — «нравится»; одна своя реакция на сообщение, повторное нажатие снимает | принято (2026-10-09) | запрос владельца 2026-10-09; ADR-24 |
| UX-15 | Ответы: свайп сообщения влево или «Ответить» в меню; цитата в сообщении, нажатие — переход к оригиналу с подсветкой | принято (2026-10-09) | запрос владельца 2026-10-09; ADR-24 |
| UX-16 | Компактный вид списка чатов (меньше высота строки) — переключатель в Настройки → Оформление, по умолчанию выключен | принято (2026-10-09) | выбор владельца 2026-10-09; макет ui-v4 |
| UX-17 | Первый запуск: приветствие → имя → создание ключей (с предупреждением «копии на сервере нет») → разрешения → проверка связи → первый контакт; ссылка «Уже пользуюсь на другом устройстве» — подключение по QR (ADR-17) | принято (2026-10-09) | макет ui-v5; `ux-guidelines.md`: Material permissions |
| UX-18 | Работа в фоне: постоянное уведомление «Соединение активно»; разрешения «Уведомления» и «Работа в фоне» — с объяснением до системного окна, можно пропустить; при отказе — баннер в чатах и отметка в Настройки → Уведомления | принято (2026-10-09) | ADR-10; `ux-guidelines.md`: Android 13, Doze |
| UX-19 | Содержимое уведомлений — 3 уровня: «Имя и текст» (по умолчанию) · «Только имя» · «Без имени и текста» — выбор в Настройки → Уведомления; отчёты диагностики — без звука; уведомление о потере связи — выкл. по умолчанию | принято (2026-10-09) | `ux-guidelines.md`: видимость на экране блокировки |
| UX-20 | Новая группа — 2 шага: участники (контакт со сменённым ключом выбрать нельзя, несверенный — с меткой) → название и правило «кто меняет состав» (только администраторы — по умолчанию / все участники). В сведениях группы: удалить участника, назначить администратора, без звука, покинуть группу | принято (2026-10-09) | R-17; ADR-3 |
| UX-21 | Ошибки связи различаются: «Телефон не в сети» и «Интернет есть, наши узлы не отвечают» — с карточкой «Что делать» на экране «Связь»; сообщения в очереди уходят сами; через 10 мин без доставки — «не доставлено» с выбором: повторить / через LoRa / удалить | принято (2026-10-09) | R-8; эвристика NN/g №9 |
| UX-22 | Пустые состояния: вместо пустого списка — объяснение и кнопки «Показать мой QR» и «Ссылка-приглашение» | принято (2026-10-09) | макет ui-v5 |
| UX-23 | «Bluetooth рядом (тест)» — пункт в Настройки → Связь и отдельный экран: переключатель (по умолчанию выключен), разрешение «Устройства поблизости» — системным окном при первом включении; при отказе — баннер с кнопкой «Настройки» и отметка в Настройках; список «Телефоны рядом» с кнопкой «Подключить»; собеседник вне досягаемости — «сообщения ждут в очереди» | принято (владелец 2026-10-10, макет ui-v6) | ADR-49, ADR-40; `ux-guidelines.md`: Material permissions |
| UX-24 | На экране Bluetooth — предупреждение: пока включено, сканер поблизости может заметить приложение; в списке только свои контакты. Как скрыть приложение от сканеров (сменяющиеся идентификаторы в объявлениях BLE) — отдельный ADR до выхода за рамки теста | принято (владелец 2026-10-10, макет ui-v6) | overview: модель угроз, метаданные |
| UX-25 | Добавление по Bluetooth рядом: вкладка «Рядом» в «Новый контакт» (четвёртая, перед «Ссылка»); оба открывают экран → «Искать рядом» → в списке только телефоны с открытым тем же экраном (имя, которое человек указал сам) → «Добавить» → подтверждение на втором телефоне → контакт «не сверен» (UX-4). Разрешение «Устройства поблизости» — системным окном при первом поиске. Пока экран открыт — предупреждение, что телефон виден другим телефонам с приложением | принято (владелец, 2026-10-10) | ADR-62, ADR-23; макет `ui-v7.html` |
