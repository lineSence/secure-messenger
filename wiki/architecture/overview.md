# Архитектура мессенджера (проект)

Статус: проектирование, кода нет. Требования владельца — `wiki/architecture/requirements.md`, решения — `wiki/architecture/decisions.md`. Факты, на которые опирается схема, — в `wiki/references/`.

## Цель
Личный мессенджер со сквозным шифрованием для узкого круга, который продолжает доставлять текст при блокировках в РФ: DPI/ТСПУ, блокировка по IP, белые списки на мобильном интернете, локальное отключение связи.

## Модель угроз
| Угроза | Чем отвечаем |
|---|---|
| DPI и поведенческий анализ ТСПУ | Сменные транспорты с маскировкой, один долгий канал, правдоподобный TLS-отпечаток |
| Блокировка IP серверов | Несколько серверов и доменов, подписанный конфиг со списком адресов, быстрый передеплой |
| Белые списки | Транспорты через разрешённую инфраструктуру (TURN видеозвонков, DNS), store-and-forward |
| Полное отключение связи | Bluetooth / Wi-Fi рядом, Meshtastic |
| Изъятие сервера | На сервере только шифротекст и случайные ID очередей, очереди в RAM, без логов |
| Изъятие телефона | Ключ базы из пароля (Argon2id), исчезающие сообщения, пароль под принуждением |
| Метаданные (кто с кем, когда) | Нет телефонов/аккаунтов, однонаправленные очереди, 2-узловая маршрутизация, паддинг, задержки, без отчётов о доставке |
| Подмена ключей | Сверка QR при встрече, пиннинг ключей, блокировка отправки при смене ключа |

## Компоненты
```
[Клиент Android]
  ├─ UI (Kotlin или Flutter)
  ├─ Ядро на Rust: протокол, хранилище (SQLCipher), очереди отправки
  │    ├─ 1:1 — libsignal (PQXDH + Triple Ratchet)
  │    └─ группы — OpenMLS
  ├─ Диагностика: проба транспортов, экран «что доступно сейчас»
  └─ Транспортный слой (сменные модули, общий интерфейс «отправить/получить блоб»)
        ├─ VLESS + XHTTP + Reality (sing-box / Xray как библиотека)
        ├─ AmneziaWG
        ├─ Hysteria2 (только Wi-Fi)
        ├─ TURN видеозвонков
        ├─ DNS-туннель (dnstt)
        ├─ почта (IMAP/SMTP)
        └─ позже: Bluetooth / Wi-Fi Direct, Meshtastic / MeshCore / Reticulum

[Российский ретранслятор]  — только пересылка шифротекста, одноразовый
[Серверы-реле за рубежом, 2–3 провайдера] — очереди сообщений в RAM, TTL
```

## Лестница транспортов
1. Обычный интернет: VLESS + XHTTP + Reality → AmneziaWG → Hysteria2 (Wi-Fi).
2. Белые списки: TURN видеозвонков → DNS-туннель → почта через российский сервис.
3. Нет связи (в будущих релизах): Bluetooth / Wi-Fi рядом, Meshtastic / MeshCore / Reticulum.

Переключение — автоматическое по результатам проб; при признаках «заморозки» (TCP установлен, данные не идут ~120 с) — сразу следующий транспорт.

## Диагностика (R-8)
- Экран «Что работает сейчас»: каждый транспорт — статус (работает / медленно / заблокирован), задержка, скорость.
- По типам данных: текст / фото и файлы / голосовые / звонки — доступно или нет при текущих транспортах.
- Проба короткая и экономная по трафику; результаты не уходят на сторонние серверы.

## Формат сообщений и сервер
- Сообщение дополняется до фиксированного размера (1 / 4 / 16 КБ).
- Отчёты о доставке и «печатает…» выключены или идут со случайной задержкой.
- Сервер: хранит зашифрованные блобы в очередях; удаляет после доставки; TTL недоставленных — 7 дней; без логов IP; tmpfs + шифрование диска.
- Конфиг (список серверов и транспортов) подписан ключом владельца, ключ хранится офлайн.

## Устройство
- Только Android (R-1); APK вне магазина, воспроизводимые сборки.
- Без FCM/APNs: постоянное соединение или UnifiedPush.
- Затирание ключей в памяти (`zeroize`), зависимости зафиксированы, feature-флаги проверяются.
