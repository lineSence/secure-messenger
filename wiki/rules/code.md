## [CODE-NO-WEAKENING] Не ослаблять проверки без ADR
Правило: Не отключать и не ослаблять линты (`[workspace.lints]`, `clippy.toml`), правила `deny.toml`, `.semgrep/`, исключения cargo-vet, ИИ-ревью и шаги `ci.yml` без нового ADR, принятого владельцем. Исключение для ИИ-ревью — запись в `.github/ai-review-waivers.json` с обоснованием и тестом. `#[allow(...)]` — только точечно и с комментарием «почему».
Почему: ослабление проверки — самый дешёвый способ «пройти» CI для агента; ADR-15, ADR-20.
